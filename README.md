# Paystiker — Строительный кэшбэк и промо-система скретч-карт

Интерактивная система мотивации мастеров и прорабов с мгновенной выплатой кэшбэка на кошельки (Dushanbe City, Alif, DC Wallet).

## 🎬 3 варианта презентации и анимации:

1. **✨ Вариант 1: Fixed Trace (`trace.html`)**  
   Интерактивная презентация с плавной кривой Безье и динамической пунктирной линией трассировки шагов механики (Скан QR ➔ Начисление ➔ Выплата).

2. **💡 Вариант 2: Porthole Spotlight (`porthole.html`)**  
   Презентация с оптическим иллюминатором и динамическим лучом прожектора, фокусирующим внимание клиента на ключевых выгодах системы.

3. **📱 Вариант 3: Мобильный PWA сайт мастера (`site.html`)**  
   Интерактивное тактильное стирание защитного скретч-слоя монетой/пальцем прямо на экране смартфона + форма моментального вывода денег.

4. **🖥 Вариант 4: React Artifact Canvas (`presentation.html`)**  
   Интерактивная канвас-доска архитектуры промо-воронки.

## 🚀 Быстрый запуск:
```bash
node server.mjs
# Открыть в браузере: http://localhost:8085
```
